PDF Email Sender Helper

Fill in your SMTP settings below and click Generate .env. This page helps you prepare settings for pdf_emailer.py.

Browser pages cannot safely send SMTP credentials directly. This HTML file is a setup helper; the actual send is done by the Python script.

Run command

After saving this as .env in the repo root, run:

set -a && source .env && set +a && python3 pdf_emailer.py
